# PavlDen Family VPN — Windows + Happ

## 1. Установка Happ

Официальная страница Happ:

https://github.com/happ-proxy

В разделе **Binaries** найдите строку **Windows** и выберите **Setup x64**. Если основная ссылка не работает, используйте **x64 (mirror)**.

Запустите скачанный файл `setup-Happ.x64.exe`, выберите язык и пройдите мастер установки. Стандартные параметры можно оставить без изменений. Пункт **Reset all cache and settings after installation** оставьте выключенным. В конце нажмите **Install**, затем **Finish**.

## 2. Добавление подписки из Telegram

1. Откройте Happ. При первом запуске появится окно **Insert**.
2. В Telegram-боте откройте **🌐 Моя подписка**.
3. Нажмите **📲 Добавить в Happ**.
4. Если Telegram спросит **«Перейти по ссылке?»**, нажмите **«Перейти»**.
5. В браузере подтвердите **Open Happ Proxy Client**.
6. Happ откроется и автоматически импортирует профиль **PavlDen Family VPN**.

## 3. Альтернативные способы добавления и переключение серверов

Если автоматическое открытие не сработало:

- Скопируйте **персональную ссылку подписки**, указанную в Telegram под QR-кодом.
- На первом экране Happ вставьте её в поле **Insert** и нажмите **Get started**.
- Либо, если профиль уже открыт, сверните список серверов и нажмите **Clipboard** — ссылка из буфера обмена будет добавлена.
- Через **QR-Code** в Windows-версии Happ нужно выбрать сохранённое изображение QR-кода.

Чтобы переключить сервер, просто нажмите на нужный сервер в списке. Выбранная строка станет активной для следующего подключения.

## 4. Обновление, проверка серверов и подключение

- Для ручного обновления подписки нажмите значок обновления рядом с **PavlDen Family VPN**. Зелёная галочка означает успешное обновление.
- **Test ping** проверяет выбранный сервер.
- Значок спидометра рядом с профилем проверяет все серверы и показывает задержку в миллисекундах.
- Выберите подходящий сервер и нажмите большую кнопку питания.
- При успешном подключении появится статус **CONNECTED**.

Если один сервер работает плохо, выберите другой и подключитесь снова.
